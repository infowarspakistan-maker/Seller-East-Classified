# ROADMAP.md

## Phase 1 — Trust-First MVP (Months 1–4)
- Web + Android
- Auth (OTP)
- Mobiles + Electronics listings
- Search, chat
- Escrow pilot (Raast + JazzCash)
- Policy pages live
- **City:** Lahore
- **Target:** 500 sellers, 2,000 listings, 200 escrow txns

## Phase 2 — Verticals & Monetisation (Months 5–10)
- Motors + Property verticals (multi-step forms)
- Store profiles for dealers/agencies
- Inspection pilot (cars)
- Promoted listings, subscriptions, lead gen
- **City:** + Islamabad/Rawalpindi
- **Target:** 100,000 MAU, 20,000 listings

## Phase 3 — Scale & Defend (Months 11–18)
- Managed logistics (<5kg, then bulky)
- AI: recommendations, price intelligence, fraud detection
- Tier-2 expansion (Faisalabad, Multan, Peshawar)
- Display ads, API access
- **Target:** 500,000 MAU, 100,000 listings, profitable in core cities

## Principles
- City density > national coverage
- Delay monetisation until liquidity
- Compliance as competitive advantage
- Ship weekly; measure everything
